
# 📅 Project Phases

The Microsoft Sentinel SOC Lab was developed in multiple phases, with each phase building upon the previous one to create a complete Security Operations Center capable of detecting, investigating, and responding to simulated cyber threats.

| Phase | Focus |
|--------|-------|
| Phase 1 | Azure Infrastructure Deployment |
| Phase 2 | Telemetry Collection & Data Ingestion |
| Phase 3 | Detection Engineering |
| Phase 4 | Attack Simulation & Validation |
| Phase 5 | Incident Investigation |
| Phase 6 | Automation & Playbooks |
| Phase 7 | Monitoring & Dashboards |
| Phase 8 | Documentation & Portfolio Development |
