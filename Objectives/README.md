
# 🎯 Objectives

The primary objectives of this project were to:

- Build a cloud-native SOC environment using Microsoft Azure and Microsoft Sentinel.
- Simulate real-world cyberattacks in a controlled lab environment.
- Develop and validate custom KQL analytics rules.
- Detect attacker techniques mapped to the MITRE ATT&CK framework.
- Investigate alerts and incidents generated during attack simulations.
- Implement automated incident response using Microsoft Sentinel Playbooks.
- Demonstrate practical SOC analyst and detection engineering skills through hands-on implementation.
