
# 📖 Project Overview

The Microsoft Sentinel SOC Lab is an end-to-end cloud-native Security Operations Center (SOC) project built on Microsoft Azure. It demonstrates the complete security operations lifecycle, from log collection and threat detection to incident investigation and automated response.

The lab includes Windows endpoints, an Active Directory Domain Controller, Microsoft Sentinel, Azure Monitor Agent (AMA), Data Collection Rules (DCRs), Log Analytics Workspace, Logic Apps, and Microsoft Defender XDR. Real-world attack simulations were performed to validate custom detection rules and investigate generated incidents.

This project showcases practical SOC analyst skills, including detection engineering, threat hunting, incident response, automation, and security monitoring.
